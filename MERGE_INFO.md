# UniServer — Integración

Esta distribución combina en un único proyecto:

- UniServer 1.1.0 original
- UI / Dashboard mejorado
- Roadmap completo de fases 0–7

El backend del proyecto original se conserva como base y los archivos de interfaz/documentación
se integran sobre él.

Antes de publicar en un repositorio, revisa que no existan secretos en `.env`, claves privadas
o credenciales dentro de los archivos versionados.
